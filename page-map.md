## Rules

- Desktop references target approximately 1440px.
- Tablet references target approximately 768px.
- Mobile references target approximately 390px.
- Use the Gulabi Threads logo from public/logo.
- Preserve the layout, visual hierarchy, typography, spacing and colours.
- Adapt intelligently between breakpoints when a device reference is unavailable.
